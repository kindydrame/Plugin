# Colis224 Logistics Manager

Plugin WordPress professionnel pour la gestion complète d'une entreprise de livraison internationale.

## Description

**Colis224 Logistics Manager** est un système complet de gestion logistique pour les entreprises de livraison internationale (Chine, France, Maroc, Sénégal, Côte d'Ivoire, Guinée).

## Fonctionnalités Principales

- ✅ Gestion des colis et suivi
- ✅ Gestion des clients (particuliers et entreprises)
- ✅ Gestion des partenaires commerciaux
- ✅ Gestion de l'équipe (agents et livreurs)
- ✅ Comptabilité complète (revenus et dépenses)
- ✅ Rapports et statistiques
- ✅ Notifications email et SMS
- ✅ Portail client avec tracking
- ✅ Système de validation hiérarchique
- ✅ Multi-entrepôts et programme de fidélité
- ✅ Paiements Mobile Money et PayPal

## Installation

1. Téléversez le dossier `colis224-logistics-manager` dans `/wp-content/plugins/`
2. Activez le plugin via le menu 'Plugins' dans WordPress
3. Accédez au menu "Colis224" dans l'administration

## Prérequis

- WordPress 6.0 ou supérieur
- PHP 8.0 ou supérieur
- MySQL 5.7 ou supérieur
